# Voice-to-Text: MP3 Speech Recognition in Python

This project converts an `.mp3` audio file to `.wav` and uses Google's Speech Recognition API to transcribe the audio into Turkish text.

## 🔧 Requirements

- Python 3.7 or higher
- [ffmpeg](https://ffmpeg.org/download.html) installed and added to PATH
- Internet connection (Google API is used)

## 📦 Installation

Install required Python libraries:

```bash
pip install -r requirements.txt
